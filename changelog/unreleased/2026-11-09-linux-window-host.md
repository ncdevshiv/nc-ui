- **The window host works on Linux.** `ncui-webview-wry` creates its event loop on a worker thread and set tao's `with_any_thread(true)` on Windows only, so tao's Unix backend panicked — "Initializing the event loop outside of the main thread" — and `ncui run` could not open a window on Linux at all. The switch is now set on the X11/Wayland targets too (AppKit has no such option, so macOS is unchanged), and the host's 8 tests, the 8 page-bridge tests and both comparison ports open genuine windows under WSLg and pass. The Linux gate grew three stages to cover it: the release configuration compiles, its unit tests run, and the real-window integration tests run.
