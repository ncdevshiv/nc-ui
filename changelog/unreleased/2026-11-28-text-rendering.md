- Text runs draw. The render plan's last loud refusal but one is gone: a custom island's `TextRun` commands shape through rustybuzz, rasterise to coverage, pack into a shelf-packed 1024² `R8` glyph atlas (`text_layout.rs` — pure CPU, 8 tests) and emit as textured quads whose texture coordinates interpolate under clipping, because a clipped textured quad is not a smaller rectangle but a smaller window on the same coverage. The pipeline is one textured path for everything — solid quads sample a white texel seeded at pipeline birth, so a rectangle and a glyph share a draw call and the shader has no branch. Proven in layers: pure expansion tests (positions, UV interpolation, full-clip absence), four GPU pixel tests (`text_pixels.rs` — an H's strokes read back taller than the gap between them, an O's counter stays dark, viewport clipping holds through the texture path, colour correctness as alpha-only modulation), and the real-Edge browser gate, where the shell fetches the font asset, shapes on wasm and the clip label lands 68 fully-covered glyph pixels in its band — in the dev bindings and the packaged release artifact both. The vertex format grew UVs (20 bytes); `QuadPipeline::new` takes the queue for the white-texel seed; `RenderPlan::from_frame` still refuses text loudly, and `from_frame_text` is the text-capable entry the shell uses. Bitmap blits remain the one loud refusal, needing the host bitmap store; what font a distributed artifact ships is a licensing decision named in the register.
