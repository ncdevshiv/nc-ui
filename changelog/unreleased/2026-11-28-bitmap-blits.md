- Bitmap blits draw — the render plan's last loud refusal is gone, and with it the `gpu.island_custom` primitive set is complete. The atlas is now RGBA and shared (`ContentAtlas`): glyph coverage lives in the alpha channel of white texels, bitmap pixels are their own texels, and one multiply in the fragment shader draws both — no branch, no second pipeline, no draw-call split. The host's new `BitmapStore` holds pixels by key and versions keys generationally, so a replaced thumbnail never collides with the packing a frame already planned samples; a blit whose key is absent draws the transparent well (documented semantics — content not yet arrived is honestly empty, and placeholders are the application's to draw beneath); a frame carrying blits with no store wired at all still refuses loudly, because that is a wiring defect, not content-in-flight. Proven in layers: pure expansion tests (white vertex colour, uv span, missing-key silence, store-less refusal), GPU pixel tests (a split red/green bitmap reads back in its own colours with correct scaling, a replacement draws the new pixels), and the real-Edge gate where the shell's deterministic gradient thumbnail reads back through compositor pixels — in the dev bindings and the packaged release artifact both. Atlas eviction remains named future work: replacement packings leave dead space until then, and the atlas-full refusal is what keeps that honest.
