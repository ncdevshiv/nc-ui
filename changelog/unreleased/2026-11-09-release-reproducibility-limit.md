- **The release build is reproducible for one directory, and that is now stated.** `tools/build_release.py` compares two clean builds by digest, and on Windows they differ by 403,978 bytes of an 11,816,448-byte binary. The bytes name the cause: a dependency's build script writes into its `OUT_DIR` and that path is compiled into the binary, so `target/release` and a temporary directory embed different strings of different lengths. Two builds into two different temporary directories differ by 69 bytes — the PE timestamp and the PDB GUID — which is what isolated the path from ordinary nondeterminism. `docs/known-gaps.md` records the limit and the registry entry no longer implies the check passes.
