- **The Linux gate compiles the release configuration.** The gate's stages all ran under the default feature set, so `ncui-webview-wry` over `wry`/`tao`, the renderer over `wgpu` and the shaper were never compiled on Linux — the shipped binary's configuration was a Windows-only assumption. The GTK and WebKit development libraries turned out to be installed in the WSL2 distro, contrary to what this project's own notes had claimed, and `cargo check -p ncui-cli --features ncui-cli/wry-host` compiles cleanly there; a new gate stage runs it on every pass. The real-window tests still cannot run (the session has no display), so a feature whose evidence opens a window stays `unverified` on Linux.
