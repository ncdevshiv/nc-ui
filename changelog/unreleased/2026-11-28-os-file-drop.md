- **`native.os_file_drop` — OS file drops reach pages as capability-shaped DOM events.** Files dragged from the OS shell onto a window now arrive at the page as `ncui:file-drop` CustomEvents with normalized absolute paths and the drop position, through the disclosure policy in `ncui_webview::filedrop`; the webview's default drop navigation is blocked so a drop cannot route around the navigation policy. Live-proven in a real window through CDP (`crates/ncui-runtime/tests/filedrop_live.rs`); registry entry added.
