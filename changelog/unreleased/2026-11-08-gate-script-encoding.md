- **The gate scripts decode git's output as UTF-8 explicitly.** Every shell wrapper calls `python3`, and the Python tools passed `text=True` without an encoding, so they decoded with the interpreter's locale default — UTF-8 on Linux and cp1252 on Windows. The pre-commit hook crashed on any staged diff containing a non-ASCII byte, which on this machine means every commit was blocked by the hygiene hook rather than checked by it. Seventeen subprocess calls across the four gate scripts, the release tooling, the coverage probe and the comparison harness now name the encoding.
