- Page commands can now be superseded before they execute: `ncui.invoke(name, payload, { supersede: "key" })` marks a command as part of a latest-wins stream, and when the pump finds a newer queued command with the same key it answers the stale one `outcome: "superseded"` without running it — a scrub applies only the newest playhead position instead of executing the whole backlog. The key is per-call because only the caller knows which of its commands form such a stream (`playhead`, `trim:clip-7`); superseded commands always receive an answer so the page's promise settles instead of timing out, and messages outside the stream are never reordered or dropped.
