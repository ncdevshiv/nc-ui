- **A GPU island row wraps its text into the lines that fit it.** The renderer's text path now shapes a row's run and breaks it at the last space on each line, between glyphs when a word is wider than the row, and at newlines; a row taller than one line shows several instead of one clipped line, centred when the block fits and top-aligned when it does not. Five unit tests pin the wrapping and an end-to-end test fetches the same row twice — once with a text far wider than the row and once with a single letter — and asserts the wrapped frame's ink spans more of the row's height.
